CSV format

Use one file per fuel, with interval energy in kWh and an explicit timestamp offset. Use the optional duration column for non-default intervals and publisher_interpolated (0 or 1) to flag filled values.

start_utc,consumption_kwh,duration_minutes
2025-01-01T00:00Z,0.42,30

The weather file accepts hourly ERA5 exports. Extra fields such as wind speed are ignored by the pattern rules.

start_utc,temperature_c
2025-01-01T00:00Z,4.5

For indoor temperature use indoor_temperature_c. For activation use heating_fraction (0 for off, 1 for on, or the share of the interval running). Match the same timestamps and include duration_minutes if needed.
